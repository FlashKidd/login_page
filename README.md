# Login Page

A simple front-end login and registration interface built with HTML and CSS. The project showcases a minimal login page with a registration form and a static background image.

## Contents

- `index.html` – the login form
- `register.html` – a registration form
- `style.css` – shared styles
- `img/` – background images (images from Pexels)

## Usage

Open `index.html` in your browser to view the login page. The forms do not submit anywhere because there is no backend implementation. You can modify `style.css` to change colors, fonts, and background images.

## Customization

Replace the images in `img/` or update the CSS `background` rule in `style.css` to use a different background. Ionicons are loaded from a CDN for the menu icon.
